# AWS Swim Set Site

## Overview

### What it Does

This site is meant to be a site that I will use to track what swim sets I swam on a given day.

### Why This Exists

In 2024, I used the MEAN stack to build a site that allowed me to track what swim sets I did on each day. This repository is that site reworked to be Cloud Native on AWS.

Goal here is to use as many technologies I know as possible to but learn to make them all Cloud Native.
